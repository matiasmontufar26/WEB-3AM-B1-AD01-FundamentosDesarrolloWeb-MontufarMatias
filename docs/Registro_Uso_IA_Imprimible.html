Prompt exacto
Desarrollar el frontend de un sistema web para un taller de mantenimiento automotriz, aplicando la estructura semántica de HTML, estilos CSS/Bootstrap y, especialmente, programación con JavaScript. Implementar formularios, validaciones, arrays de objetos, eventos, login básico, roles y CRUD sin backend ni base de datos.
Respuesta aprovechada

1. Interfaz y semántica: Estructuración modular con Header, Navbar responsiva, Hero, catálogo dinámico de servicios, formulario con todos los controles requeridos, vista de cliente y panel administrativo.

2. Lógica JavaScript: Arrays de objetos precargados, métodos de manipulación funcionales (forEach, filter, find, map, for, for...of), control de acceso RBAC e integración de alertas SweetAlert2.

3. Validaciones con RegExp: Placa vehicular ecuatoriana (^[A-Z]{3}-\d{3,4}$), años entre 1990 y 2027, kilometraje mayor a 0 y horarios laborales (08:00 a 17:30).

Fuentes informales y sugeridas por IA (al menos 3)
  • Diseño de interfaz y maquetación (Bootstrap): Asistencia en el diseño de tarjetas de servicios, cuadrícula responsiva y modal de autenticación con botones de prueba rápida.
  • Lógica de autenticación y roles (JavaScript): Orientación en el manejo de arreglos para cuentas de prueba, sincronización de estados y validación de permisos en cliente.
